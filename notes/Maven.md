# Maven

## What is Maven?

A build automation and dependency management tool for Java.

---

## Maven Repository

Stores Java libraries online.

---

## Local Repository (.m2)

Stores downloaded dependencies locally.

---

## Why Maven?

- Dependency Management
- Build Automation
- Version Management
- Faster Builds

## Binary vs Source

### Binary
- Ready to use
- No compilation required
- Used by application developers

### Source
- Contains source code
- Needs compilation/build
- Used when modifying or contributing to Maven itself

## Verify Maven Installation

Command

mvn -version

Output

- Maven Version

- Java Version

- Maven Home

- OS Details

- Platform Encoding
